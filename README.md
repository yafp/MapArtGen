# MapArtGen

## Structure

- `MapArtGen.html` contains the application markup.
- `MapArtGen.css` contains all presentation styles.
- `js/presets.js` contains the palette catalog and normalized preset data.
- `js/app.js` contains state, map, geocoding, preview, UI, and export behavior.


## About
MapArtGen is a free Map Art Generator.

Select a location, configure a few parameters, and generate or export a high-resolution graphic for printing.

Terrain height shading uses public Terrarium elevation tiles and derives its highlight and shadow variations from the selected mountain color. The same elevation data can be exported as a watertight binary STL terrain model for 3D printing. Layer order can be adjusted with the controls under Colors, and optional scale and north annotations appear in both the preview and graphic export.

It is inspired by [Urbanmapdesign.com](https://www.urbanmapdesign.com).
